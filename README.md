# 飞书组织架构维护系统

> 版本：v1.0 · 日期：2026-09-15  
> 状态：首版代码与代码审查完成；真实 MySQL 和飞书企业环境尚未联调，未部署。

## 已确认的关键规则

- 一个实例连接一个飞书组织，使用独立数据库。
- 部门、人员、上下级和主部门以飞书为准，本地只维护门店标记、可选门店编码和备注。
- 部门可逐个或批量标记为门店；标记不向下继承。
- 员工每条部门关系向上寻找最近的门店，合并形成所属门店列表。
- **飞书主部门向上寻找最近的门店，形成主门店。** 主部门不在门店下时主门店为空，不从其他兼职门店中猜选。
- 订阅飞书变更，支持全量更新、所选部门及全部后代更新、每日全量核对。
- 保留失效记录和变更日志，不提供任意日期的完整组织还原。
- 飞书登录加管理员白名单；其他系统使用独立凭据调用只读 API，首版不向其他系统推送变更。

本目录是新的独立方案基线，保留原方案作为背景资料，不直接继承其中全部约束：

| 原资料 | 本方案沿用 | 本方案调整 |
| --- | --- | --- |
| [首版范围](../../phase-1/first-release-scope.md) | 组织与业务数据分开、同步需可追溯 | 取消 SaaS、多租户、多渠道及一体化资产交付 |
| [组织与身份中心需求](../../phase-2/organization-and-identity-requirements.md) | 组织树、人员多部门关系、本地门店信息、外部稳定标识 | 固定飞书为唯一来源，取消本地组织人员新增和通用字段绑定配置 |
